# 🍱 LunchFlow Pro - Office Lunch Management System

A categorized office lunch counter, accounting, and monthly financial settlement system built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

## Features
- **Departments Covered**: Software, Backend, Front-end, Marketing, Business, Design, UI/UX.
- **Categorized Meals**: Regular Lunch, Premium Lunch, Diet Lunch, and Guest Portions.
- **Monthly Closing**: 100% mathematically exact multi-category settlement ledger with balance carryover.
- **Exporting**: Excel (.csv) report and print-ready PDF slips.

## Quick Start
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

## Push to GitHub & Deploy on Vercel
```bash
git init
git add .
git commit -m "feat: initial commit LunchFlow Pro"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/lunchflow-pro.git
git push -u origin main
```
Import the repository on [vercel.com/new](https://vercel.com/new) and click **Deploy**.
