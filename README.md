# 🍱 LunchFlow Pro - Office Lunch Management System

Categorized office lunch counter, accounting, and monthly financial settlement system built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

## Quick Start
```bash
npm install
npm run dev
```

## Push to GitHub & Vercel
```bash
git init
git add .
git commit -m "feat: initial commit"
git branch -M main
```
Deploy directly on [https://vercel.com/new](https://vercel.com/new).
